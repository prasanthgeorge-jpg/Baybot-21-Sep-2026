Stripe Payment Test

Internal page to verify the Stripe Elements integration

Test Mode

What this page does

Test mode only. This page uses a Stripe test publishable key, so no real card is ever charged. Use any of Stripe's test card numbers — e.g. 4242 4242 4242 4242, any future expiry, any 3-digit CVC.

This is a standalone test harness, not wired into the Parts Store cart. It mounts a Stripe Card Element and, on submit, tokenizes the card into a PaymentMethod directly in the browser — that confirms the publishable key, card validation, and Stripe.js are all working.

This repo now has serverless api/ functions (chat, lead, demo-request), so a real api/create-payment-intent.js using a Stripe secret key could be added for a fully server-confirmed charge. That key must never be placed in this file or any other client-side code.
